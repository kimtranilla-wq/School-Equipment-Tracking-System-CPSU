ALGORITHM NOTES

What the code demonstrates

Linear Search

Checks each equipment record sequentially and is used for general field searching.

O(n)

Binary Search

Searches for an Equipment ID after ordering a copy of the IDs; each step halves the search range.

O(log n)

Bubble Sort

Compares adjacent records and swaps out-of-order values to organize the equipment list.

O(n²)

BST Search & Traversal

Follows tree branches to locate an ID. In-order traversal visits IDs in sorted order.

O(h)
Presentation note

Dashboard and report status totals represent units (the sum of Quantity). The BST, activity stack, and maintenance queue operate on equipment records, not individual units.
